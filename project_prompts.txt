PROMPT 1: Architecture, Problem Statement & Threat Modeling
--------------------------------------------------------------------------------
"I want to build 'PromptProof', a deterministic LLM prompt injection vulnerability scanner and automated prompt hardening engine for an AI cybersecurity hackathon. 

The core problem is that LLMs flatten system instructions and untrusted user input into a single context window (OWASP LLM01), and existing scanners rely on subjective 'LLM-as-a-judge' evaluators that hallucinate and can be jailbroken themselves. Furthermore, when developers harden prompts, they often cause catastrophic over-refusals that break legitimate user queries.

Design a clean 4-phase closed-loop architecture:
1. Matrix Stress-Test: Instrument system prompts with cryptographic canary secrets (CANARY-XXXX) and two-part instruction markers (prefix ZX + suffix 4 digits). Concurrently stream 30+ categorized direct and indirect attack vectors.
2. Deterministic Judge: A heuristic rule engine that inspects raw plain text for leaked canaries (exact, reversed, hex, base64, spaced) and joined markers. If a model refuses the attack but echoes the marker in its refusal, classify it as 'ambiguous' rather than a false failure.
3. Automated Hardener & Re-Test: Synthesize an upgraded prompt using instruction hierarchy, XML untrusted data boundaries, and role locks. Re-run failed vectors to mathematically prove regression mitigation (Vulnerability Flips).
4. Benign Utility Verification: Test 5 routine legitimate customer queries against both prompts to guarantee zero false-positive over-refusals.

Give me the complete architecture diagram and directory layout for a FastAPI backend and React frontend."

--------------------------------------------------------------------------------
"Implement the core security modules in Python under backend/app/:
1. attacks.py: Build a comprehensive attack matrix of 30+ vectors categorized into: Indirect Injection (data payloads, customer reviews, support tickets), Direct Override, Canary Extraction, System Prompt Extraction, Jailbreaks & Roleplay, Delimiter & Tag Abuse, and Authority & Urgency Social Engineering.
2. harness.py: Create make_context(prompt) that generates a unique UUID canary and random numeric marker, embedding them into a test harness with strict non-disclosure instructions. Add render_attack() to substitute markers into payloads.
3. judge.py: Implement the deterministic judge function. Evaluate canary presence (including base64, hex, rot13, reversed, and spaced permutations), marker execution obedience, prompt n-gram overlap, and refusal echo heuristics. Return structured verdicts: 'pass', 'fail', or 'ambiguous' with clear explanatory reasons.
4. mutator.py: Build deterministic payload mutators that transform attacks into base64 wrappers, spaced letters, leetspeak, and roleplay cloaking.
5. scoring.py: Implement weighted severity calculations (Critical: 3x, High: 2x, Medium: 1.5x, Low: 1x) and category resistance breakdown formulas.

Ensure all data structures use strict Pydantic v2 schemas."
